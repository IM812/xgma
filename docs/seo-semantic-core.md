## Что сделано технически
- Боевой домен: `https://xgma-rus.com`. На него указывают canonical, `sitemap.xml`, Open Graph и микроразметка, даже если сайт открыт на `*.vercel.app`.
- Телефон `+7 (985) 418-88-14` задан в одном месте (`lib/site.ts`) и выводится в шапке, подвале, контактах, мобильной панели, на странице дилеров и в микроразметке (в формате `+79854188814`).
- Уникальные title и description на каждой странице, canonical, Open Graph, `manifest.webmanifest`.
- Микроразметка: Organization, WebSite, Product (с характеристиками), BreadcrumbList, NewsArticle / Article.
- `sitemap.xml` генерируется автоматически (страницы, категории, модели, новости). Журнал `/articles` закрыт `noindex` и в sitemap не входит.
- `robots.txt` с директивой `Clean-param` для Яндекса (utm-метки, yclid, gclid, ysclid), чтобы ссылки с рекламы не плодили дубли.
- Preview-сборки Vercel полностью закрыты от индексации (`Disallow: /` и `noindex`), индексируется только production.
- Яндекс Метрика: вебвизор, карта кликов, точный показатель отказов, учёт переходов внутри сайта. Цели отправляются автоматически:
  `phone_click` (клик по телефону), `email_click` (клик по почте), `form_submit` (отправка любой формы).

## Переменные окружения (Settings → Vars)
| Переменная | Значение | Где взять |
|---|---|---|
| `NEXT_PUBLIC_YANDEX_METRIKA_ID` | номер счётчика, например `98765432` | metrika.yandex.ru → Добавить счётчик, адрес `xgma-rus.com` |
| `NEXT_PUBLIC_YANDEX_VERIFICATION` | код из мета-тега | webmaster.yandex.ru → Добавить сайт → способ «Мета-тег», только значение `content` |
| `NEXT_PUBLIC_GOOGLE_VERIFICATION` | код из мета-тега | search.google.com/search-console → Префикс URL → «Тег HTML», только значение `content` |
| `NEXT_PUBLIC_SITE_URL` | не обязательно | только если домен изменится; по умолчанию `https://xgma-rus.com` |

После добавления переменных нужен новый деплой (Publish).

## Чек-лист запуска
1. Подключить домен `xgma-rus.com` в Vercel (Settings → Domains), `www.xgma-rus.com` настроить редиректом на основной.
2. Добавить переменные из таблицы выше и опубликовать сайт.
3. Яндекс Вебмастер: подтвердить права, добавить `https://xgma-rus.com/sitemap.xml` (Индексирование → Файлы Sitemap),
   указать регион (Информация о сайте → Регион), привязать счётчик Метрики (Настройки → Привязка к Метрике).
4. Метрика: в «Целях» создать JavaScript-события `phone_click`, `email_click`, `form_submit`.
5. Google Search Console: подтвердить права и отправить тот же `sitemap.xml`.
6. Добавить организацию в Яндекс Бизнес и 2ГИС с тем же телефоном и адресом.
7. Снять частотность по таблицам выше в Wordstat и скорректировать приоритеты.
8. Заменить заглушки реквизитов (ИНН, ОГРН, адрес) в `lib/site.ts` и проверить почту `info@syagong-rus.ru`: она тоже попадает в микроразметку.

## Про «ИИ-тексты»
Поисковики не наказывают за ИИ как таковой, они понижают бесполезный и массовый контент.
Поэтому:
- Статьи журнала (`/articles`), которые генерирует модель, сейчас закрыты `noindex`, пока их не проверит человек.
- Перед публикацией в каждую статью нужно добавить то, чего нет у модели: реальные цифры и фото с ваших поставок,
  комментарий инженера, ответы на вопросы клиентов, ссылки на документы завода.
- Указывайте автора (имя, должность) и дату обновления; убирайте `noindex` только у проверенных материалов.
- Не публиковать много однотипных страниц сразу: 2–4 сильных материала в месяц лучше сотни шаблонных.
